# 项目章程

## 一句话定位
使用 Python 和 ZOS-API 自动改变镜片厚度或曲率，并编排 Zemax
对每个参数案例进行真实分析和内置优化，从而获得参数变化与光学性能
之间的规律；在满足加工约束的前提下，筛选性能良好且对制造误差不敏感的候选设计。

## Zemax 负责
- 光线追迹
- MTF、Spot、Merit Function
- DLS、Hammer 等内置优化
- 原生公差与敏感度分析

## Python 系统负责
- 创建安全的模型副本
- 批量生成和执行案例
- 调用 Zemax 分析与优化
- 隔离案例状态
- 保存配置、日志和原始结果
- 比较候选并生成报告

## 本期要做
先完成一个真实模型、一个外层参数、三类真实指标和一条完整实验链路。

## 本期不做
- 不重写光线追迹和 Zemax 优化器
- 不宣称得到数学上的全局最优
- 不先做 GUI
- 不允许 Agent 绕过安全规则修改模型


### V1.0 主研究问题

当一个指定镜片厚度在合法加工范围内变化时，允许 Zemax
重新优化少量授权变量，系统能否自动获得真实性能剖面，
并找出性能良好、约束合法且对局部制造误差不敏感的候选区域？
