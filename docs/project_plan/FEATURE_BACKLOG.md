| 优先级 | 功能 | 为什么需要 | 怎样算完成 |
|---|---|---|---|
| P0 | 真实 ZemaxBackend | 正式结果必须来自 Zemax | 能连接、打开副本、读写、分析和关闭 |
| P0 | 源模型保护 | 防止实验损坏原始模型 | 运行前后源模型哈希不变 |
| P0 | MF/MTF/Spot 适配器 | 统一比较口径 | 结果包含视场、波长、单位和设置 |
| P0 | Mock 数据门禁 | 防止模拟数据进入正式报告 | 每个结果都有明确 `data_source` |
| P0 | 实验运行清单 | 支持追溯和复现 | 每次运行产生 manifest |
| P0 | 基准案例定义 | 保证所有实验比较同一个问题 | 冻结模型、外层厚度、授权变量、合法范围和分析设置 |
| P0 | 厚度参数化优化 | 获得厚度变化对应的可达性能规律 | 每个厚度案例均调用真实 Zemax 分析或优化并保存结果 |

| P1 | 多起点优化 | 缓解初值依赖 | 多次优化结果可比较 |
| P1 | 自适应探索 | 减少无意义的计算 | 同等预算下与固定扫描比较 |
| P1 | 候选局部稳健性 | 避免选择对加工误差过度敏感的尖锐最优点 | 对前 3—5 个候选执行小扰动并比较性能波动 |

| P2 | 受控 Agent | 自动选择批准的策略 | 不能越过 Schema 和安全策略 |
| P2 | GUI | 改善结果浏览 | 核心 CLI 稳定后再实现 |
| P2 | 曲率外层探索 | 验证框架可以处理第二种连续参数 | 厚度工作流稳定后复用同一实验框架 |
| P2 | 材料候选比较 | 比较少量真实玻璃候选 | 使用离散材料列表，不进行无意义的连续扫描 |
| P2 | 膜层候选比较 | 扩展到透过率、反射或鬼像问题 | 单独定义评价指标后再进入主流程 |
