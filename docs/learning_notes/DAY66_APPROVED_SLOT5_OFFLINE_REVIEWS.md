# Day 66：执行获批的 Slot 5 离线复核

## 为什么今天做

Day65 已经完成最小权限审批。Day66 需要真正消费一次授权，验证维护流程能否同时处理“可以完成的任务”和“因为证据不足而不能完成的任务”。

## 和昨天的关系

Day65 冻结了新的 ±0.012 mm 定位精度、16 个现有测量点和两个同槽任务。Day66 只能在这些冻结输入上工作，不能新增光学测量或插值。

## 核心概念

### 1. 顶层成功与子任务状态

执行包可以成功完成授权校验、计算和证据写入，但 Day27 科学复核仍可能处于阻塞状态。因此总结果必须同时表达：

- Day26：`COMPLETED`；
- Day27：`BLOCKED_BY_MISSING_EXACT_MEASURED_STATES`；
- 执行包：`success`。

### 2. Day26 的变化专用重算

边界夹区仍为 0.002 mm 和 0.005 mm。与新的 0.012 mm 定位精度相比，它们分别占 16.7% 和 41.7%。因此：

- 1 μm 数值规则仍要求继续加密；
- 匹配定位精度规则停止；
- 匹配 0.020 mm 回差规则停止。

### 3. Day27 为什么不能继续验收

新的 ±0.012 mm 包络要求命令中心两侧存在精确测量。当前缺少：

`-0.012、+0.008、+0.012、+0.018、+0.022、+0.032、+0.042 mm`。

缺失点意味着不能判断相应命令包络通过或失败，不能把未知状态当作 FAIL，更不能用插值绕过证据要求。

### 4. 同槽分支隔离

Day26 和 Day27 同处 Slot 5，但它们是独立兄弟任务。Day27 阻塞后，Day26 的有效结果仍应保留。

## 操作流程

先运行只读计划检查：

```powershell
python scripts/demos/day66_approved_slot5_offline_reviews_plan.py
```

确认计划后，执行一次获批离线包：

```powershell
python scripts/demos/day66_execute_approved_slot5_offline_reviews.py
```

## 完成标准

- Day65 审批只消费一次；
- Day26 输出 6 条明细和 3 条策略汇总；
- Day27 输出 12 条精确状态可用性记录；
- 缺失状态被标记为阻塞，不插值、不误判失败；
- 不连接 ZOS-API、不修改冻结来源；
- Slot 6 保持锁定并等待 CP09。
