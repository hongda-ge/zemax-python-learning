# Day 8：面 2 空气间隔的局部稳健性

## 1. 今天回答的问题

Day 7 使用 `0.5 mm` 步长完成粗扫描，并发现原始厚度 `6.0075511 mm`
在五个采样点中综合表现最好。Day 8 不再扩大变量数量，而是在该厚度附近进行局部加密，回答：

> 这个候选是对厚度变化非常敏感的尖锐最优点，还是附近存在性能相近的区域？

## 2. 实验方法

- 外层参数：LDE 面 2 厚度，即第一片与第二片之间的空气间隔。
- 扫描范围：`5.6075511–6.4075511 mm`。
- 扫描步长：`0.1 mm`。
- 案例数量：9 个，包含唯一的基准案例 `fine_005`。
- 每个案例都从原始模型的独立副本开始，避免累积修改。
- 每次修改厚度后执行 Quick Focus，再提取三个视场的 Standard Spot RMS 半径。
- 原始模型、初始工作副本和 ZOS-API 连接均通过安全审计。

完整九点执行前，先单独运行 `fine_005`，并逐项复现了 Day 7 的焦距和三个视场 RMS，
证明实验流程具有重复性。

## 4. 怎样理解“局部平台”

本次采用一个透明的项目判断规则：

> 若某点的三视场平均 RMS 不比当前采样最低值高超过 5%，则将其暂时划入近优平台。

按此规则，`fine_003–fine_006` 属于近优平台，对应已采样厚度范围：

```text
5.8075511–6.1075511 mm
```

这说明基准点附近不是一个明显孤立的尖锐最低点。但是，`5%` 是项目中的比较规则，
不是 Zemax 评价函数，也不是正式的机械加工公差。

## 5. 视场之间的权衡

- 0° 视场在约 `5.7076 mm` 时最好，随后随厚度增加而变差。
- 14° 视场在当前区间内随厚度增加持续改善。
- 20° 视场在约 `6.0076 mm` 时最好，向两侧移动都会变差。
- 因此不能只看一个视场，也不能只看一个平均数；原始三视场数据必须保留。

## 6. 焦移灵敏度

局部线性拟合得到：

```text
焦移灵敏度约为 -2.2935 mm/mm
R² = 0.999987
```

在本次局部范围内，面 2 空气间隔每增加 `0.1 mm`，重新对焦所需的像面移动约为
`-0.229 mm`。这描述的是当前模型的局部补偿关系，不应直接外推到更大的厚度范围。

## 7. 今天学到的工作方法

1. 粗扫描负责定位候选区域，精细扫描负责判断候选附近的曲线形状。
2. 正式批量运行前先复现基准点，可以发现设置漂移或分析配置变化。
3. 单个最低点不一定适合制造，应同时观察近优区域和性能波动。
4. Python 负责实验编排、审计和比较；Zemax 负责真实光学计算。
5. 当前结论只基于 Standard Spot，后续仍需使用 FFT MTF 或 Merit Function 交叉验证。
