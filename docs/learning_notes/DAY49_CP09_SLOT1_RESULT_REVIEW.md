# Day49：CP09 Slot 1 结果审核

## 1. 为什么 Day48 成功运行后还要审核

脚本没有报错，只能证明程序走到了结尾。维护审核还需要回答：

- 是否使用了获批候选；
- 是否只执行了一次；
- 结果是否完整；
- 新旧数值变化是否能够由输入变化解释；
- 正式配置和候选是否保持不变；
- 是否错误释放了下游任务。

因此 Day48 结束后处于 `CP09=PENDING`，Day49 才形成槽门审核结论。

## 2. 任务 PASS 与案例 PASS

这是今天最重要的区别。

### 任务审核 PASS

表示：

- 使用正确输入；
- 按审批执行一次；
- 输出完整；
- 数值变化可解释；
- 安全边界有效。

### 教学案例 PASS

表示某个测量案例在指定半行程和误差合成规则下满足条件。

Day48 两种策略都是 `4/6` 案例通过，但这不是程序故障。失败的端点正是研究结果的一部分，所以 Slot 1 任务仍可审核为 PASS。

## 3. 如何判断数值变化合理

定位精度从 `0.010 mm` 增加到 `0.012 mm`：

- 线性合成余量应增加 `0.002 mm`；
- RSS 合成余量应按平方和重新计算；
- 测量得到的调焦需求没有变化；
- 因而所需半行程的增量应等于合成余量的增量；
- 如果通过/失败案例集合没有跨过阈值，则集合应保持不变。

Day49 用完整精度验证这些关系，而不只比较终端四舍五入后的数字。

## 4. CP09 通过为什么仍不释放 Slot 2

CP09 审核结论和 Slot 2 执行审批是不同权限：

```text
Slot 1 结果审核通过
  ≠ Slot 2 已批准执行
```

Day49 只允许提交 Slot 2 释放申请。下一步仍需要单独审批，并绑定 Day49 审核记录的 SHA256。
