# Day73 获批的零偏移恢复控制重试

## 为什么今天做

Day72 已签发一次新的重试审批。Day73 使用该审批尝试建立一个 Standalone ZOS-API 连接，从而验证许可证是否真正恢复。

## 和昨天的关系

Day72 只批准重试，没有连接 Zemax。Day73 是实际验证步骤，但范围仍只有一个零偏移控制，不包含七个恢复测量点。

## 核心概念

### 1. 新旧授权严格分离

Day69 授权已经消费且不可复用。Day73 只接受 Day72 审批，并在连接前写入新的消费标记。

### 2. 成功和失败都是有效证据

- 连接成功：导出一次 Spot 和 FFT MTF，复现历史控制并验证许可证恢复；
- 连接失败：记录错误、模型哈希和授权状态，不产生光学结论。

两条路径都必须停在 CP09。

### 3. 不允许自动连续重试

Day73 只允许一次连接尝试。即使错误与 Day70 相同，也不能再次运行；必须先审核新的失败结果。

### 4. 光学与安全双重验证

连接成功后仍需满足：

- Spot 和 FFT MTF 在冻结容差内复现；
- 均衡四指标 AND 规则通过；
- 输入模型和磁盘副本不变；
- Standalone 连接关闭；
- 未使用 Quick Focus、优化或 SaveAs。

## 操作流程

先运行只读计划：

```powershell
python scripts/demos/day73_approved_recovery_baseline_retry_plan.py
```

计划通过后，只运行一次专用入口：

```powershell
python scripts/demos/day73_execute_approved_recovery_baseline_retry.py
```

如果命令返回失败，不要再次运行，应保留结果并进入下一天的 CP09 审核。

## 完成标准

- Day72 审批只消费一次；
- 只尝试一个零偏移控制；
- 成功时复现历史 Spot/MTF 并关闭连接；
- 失败时保存异常和安全审计；
- 两种路径都锁定额外重试、七点批次、Day27 重算和 Slot 6。
