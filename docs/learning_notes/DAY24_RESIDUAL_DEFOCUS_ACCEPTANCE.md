# Day 24：把残余离焦响应转换为可审计的验收判断

## 今天解决的问题

Day 23 已经测得七个残余离焦位置的 Spot 和 FFT MTF，但“得到一组性能数字”还不等于“知道哪些位置合格”。Day 24 继续回答：

> 当验收指标和阈值被明确写出后，七个实测残余离焦点分别通过哪些规则、又被哪些短板淘汰？

本日只复用 Day 23 的冻结数据进行离线判断，没有连接 ZOS-API，也没有产生新的光学指标。

## 为什么不能使用一个综合分数

Spot RMS 和 MTF 的物理含义、单位及评价方向不同：

- Spot RMS 越小越好，单位为微米；
- MTF 越大越好，是无量纲数值；
- 平均 MTF 描述总体表现；
- 最小 MTF 暴露最弱视场或方向。

如果把它们随意加权成一个分数，较好的平均值可能抵消很差的短板，而且权重本身会成为隐藏假设。因此 Day 24 使用逻辑“且”：

```text
工况通过
= Spot平均RMS通过
且 Spot最差视场RMS通过
且 MTF30最小值通过
且 MTF50最小值通过
```

任意一项失败，整个工况就失败；每个失败原因都会单独保留。

## 三档教学验收场景

| 场景 | Spot平均最大值 / μm | Spot最差视场最大值 / μm | MTF30最小值下限 | MTF50最小值下限 |
|---|---:|---:|---:|---:|
| 严格保护 | 11.1 | 16.0 | 0.18 | 0.06 |
| 均衡验收 | 11.3 | 16.5 | 0.16 | 0.05 |
| 宽松教学 | 11.5 | 17.0 | 0.13 | 0.04 |

这些数字只用于学习如何声明和审计验收规则，不是探测器要求、产品规格或制造公差。三档阈值按顺序逐步放宽，因此后一档的实测通过集合不应比前一档更小。

MTF30 和 MTF50 的平均值仍写入结果文件供观察，但不参与 PASS/FAIL，避免平均值掩盖最差方向。

## 实测点验收结果

| 残余离焦 / mm | 严格保护 | 均衡验收 | 宽松教学 |
|---:|---|---|---|
| -0.050 | FAIL | FAIL | FAIL |
| -0.020 | FAIL | FAIL | PASS |
| -0.010 | FAIL | FAIL | PASS |
| 0.000 | FAIL | PASS | PASS |
| +0.010 | PASS | PASS | PASS |
| +0.020 | PASS | PASS | PASS |
| +0.050 | FAIL | FAIL | PASS |

通过数量依次为：

```text
严格保护：2/7
均衡验收：3/7
宽松教学：6/7
```

结果符合逐步放宽规则，但通过数量只是摘要，不能替代逐项失败原因。

## 严格保护场景怎样解读

只有 `+0.010 mm` 和 `+0.020 mm` 通过全部四项。

值得注意的是，零偏移 `defocus_004` 也失败了，唯一失败项是：

```text
Spot最差视场 = 16.0807172 μm
严格上限       = 16.0000000 μm
超出           = 0.0807172 μm
```

这说明严格场景并不是“保护现有基准”，而是提出了一个比基准更严格的目标。在真实项目中，如果名义设计都无法通过规格，应先确认：

1. 规格是否确实要求优于当前名义设计；
2. 名义设计是否需要重新优化；
3. 阈值是不是在缺少应用需求时被随意设得过紧。

不能为了让基准通过而偷偷修改数据，也不能看到基准失败就自动认定程序错误。

## 均衡场景的边界案例

均衡场景通过 `0.000、+0.010、+0.020 mm` 三个实测点。

`defocus_003` 的终端摘要显示：

```text
MTF50最小值 ≈ 0.0500
```

但用于判断的完整数值是：

```text
实测值 = 0.049970
阈值   = 0.050000
短缺   = 0.000030
```

所以它必须判为 FAIL。显示时的四舍五入只用于阅读，验收时必须使用原始精度。工程报告还应声明数值精度、比较规则以及等于阈值时是否通过；本项目采用 `>=` 或 `<=`，等于阈值算通过。

## 宽松场景为什么只淘汰 -0.050 mm

宽松场景中，除 `-0.050 mm` 外其余六个实测点全部通过。`-0.050 mm` 并不是只差一点，而是四项指标全部失败：

- Spot 平均 RMS 超限；
- Spot 最差视场 RMS 超限；
- MTF30 最小值不足；
- MTF50 最小值不足。

这说明在当前实测数据和教学阈值下，负向大离焦表现出一致性的性能退化。它不能证明所有负离焦都比正离焦差，只能描述当前七个测量点。

## 为什么不能把绿色格子直接写成连续容差

例如宽松场景在已测的 `-0.020、-0.010、0、+0.010、+0.020、+0.050 mm` 上通过。可以准确表述为：

> 在上述六个实测位置，四项宽松教学规则均通过。

但不能直接表述为：

> 连续容差是 `[-0.020,+0.050] mm`。

因为 `+0.020` 与 `+0.050 mm` 之间没有测量点，指标可能在中间发生非单调变化。矩阵中的格子是离散证据，不是连续函数。若要建立连续容差，至少需要更密集的边界扫描、复现性检查和经过声明的插值或保守包络方法。

## PASS/FAIL 矩阵怎样阅读

- 横轴是七个实际测量过的残余离焦位置；
- 纵轴是三套预先声明的教学规则；
- 绿色表示该点四项指标全部通过；
- 红色表示至少一项失败；
- 矩阵不连接相邻格子，也不表达格子之间的状态。

它适合快速查看“规则改变后哪些已测点发生状态变化”，而详细 CSV 则用于查看具体失败指标和距离阈值的余量。

## 安全与证据审计

- Day 23 分析报告由 SHA256 指纹锁定；
- 七个 case ID、偏移位置和指标字段均经过验证；
- 没有连接 ZOS-API；
- 没有复制、修改或保存 Zemax 模型；
- 没有产生新的 Spot 或 MTF；
- 没有插值、外推或曲线拟合；
- 没有隐藏加权分数；
- 平均 MTF 与最小 MTF 保持分离；
- 没有把教学阈值解释为工程规格；
- 没有给出唯一工程优胜者。

## 今天掌握的核心概念

- 光学数据只有结合明确需求才能转化为合格判断；
- 多指标验收必须说明 AND、OR 或其他组合逻辑；
- 逐项余量和失败原因比一个总分更可审计；
- 显示精度不能替代计算精度；
- 名义设计也必须接受同一套规格检查；
- 离散实测通过集合不等于连续容差区间；
- 放宽阈值会扩大通过集合，但不会自动使规则更合理。
