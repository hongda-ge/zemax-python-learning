# Day 77：CP09 七点恢复批次复核

Day 77 只做离线审核，不连接 ZOS-API。审核对象是 Day 76 的七个精确定位状态，以及每个状态对应的 Spot、FFT MTF、工作副本和连接关闭证据。

本阶段最重要的学习点是区分两类结果：

- **程序执行结果**：API 是否成功、原始文件是否存在、连接是否关闭、模型是否保持不变；
- **教学验收结果**：Spot mean、Spot worst、MTF30 minimum、MTF50 minimum 是否同时满足冻结阈值。

因此，一个案例可以“程序执行成功，但教学验收 FAIL”。Day 76 中 `-0.012 mm` 与 `+0.042 mm` 属于这种情况，不应被当成 API 失败，也不能因此丢弃测量证据。

Day 77 通过后只获得申请 Day 27 离线重算的资格。Day 27 重算、Slot 6 和任何新的 ZOS-API 执行仍需独立审批。
