# Day 60：获批的Day25零偏移基线控制

## 为什么今天做

Day59只签发了一个最小范围的ZOS-API授权。Day60通过专用入口消费该授权，先确认零偏移控制仍能复现，再决定是否值得申请九点边界扫描权限。

## 和Day59的关系

Day59冻结了审批对象、模型指纹、分析配方、输出目录和停止条件。Day60不能扩大这些边界，只能执行一次`boundary_control_000`。

## 核心概念

### 1. 一次性授权消费

程序在连接Zemax前创建消费标记。标记或结果一旦存在，PLAN和执行入口都会拒绝再次使用Day59审批。

### 2. 控制复现

相同的聚焦模型、像面位置、Standard Spot和FFT MTF配方，应复现历史Day25控制。Spot和MTF分别使用冻结容差判断。

### 3. 历史复现与验收规则是两道检查

- 历史复现回答“自动化链路和配方是否漂移”；
- 均衡四指标AND规则回答“零偏移点是否仍满足既定教学验收”。

二者都通过，才说明控制证据完整。

### 4. 执行成功不释放后续批次

Day60完成后必须停在CP09。九个边界案例仍需单独审核和审批，Slot5-6也不能自动释放。

## 安全边界

- 只运行一个零偏移案例；
- 只允许一个Standalone连接和一个工作副本；
- 禁止Quick Focus、优化和SaveAs；
- 输入模型、Day25配置、历史控制和Day59审批必须保持原指纹；
- 不声明连续容差，也不批准工程变更。

## 完成标准

- Day59审批只消费一次；
- Spot和FFT MTF复现历史控制；
- 均衡四指标全部通过；
- 输入模型和磁盘工作副本不变；
- Standalone连接关闭；
- 九点边界批次和Slot5-6继续锁定；
- 输出停在CP09等待人工审核。
