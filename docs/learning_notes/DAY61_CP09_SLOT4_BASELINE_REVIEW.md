# Day 61：CP09 Slot 4 零偏移控制审核

## 为什么今天做

Day60虽然程序运行成功，但成功日志还需要转化为可复核的维护证据。Day61在不连接Zemax的情况下，审核授权、数据文件、复现结果和安全收尾是否形成闭环。

## 和Day60的关系

Day60负责产生一次光学控制结果；Day61负责判断该结果是否完整可信。审核通过只表示可以申请九点边界批次审批，不表示批次已经获准。

## 核心概念

### 1. 授权闭环

Day59审批、Day60消费标记和Day60结果必须引用同一个决策编号与审批SHA256。这样可以证明结果来自正确且只使用一次的授权。

### 2. 原始证据指纹

除了结果JSON，还要审核Standard Spot文本、FFT MTF文本、聚焦模型和磁盘工作副本。每份关键文件都用SHA256绑定。

### 3. 两道独立检查

- 历史复现检查自动化链路和分析配方是否漂移；
- 均衡四指标AND规则检查零偏移控制是否仍满足冻结教学阈值。

### 4. 审核与执行继续分离

CP09审核PASS只允许提交九点批次审批申请。Day60不能重跑，九点案例不能自动执行，Slot5-6也不能释放。

## 完成标准

- 一次性授权消费链完整；
- Spot和MTF原始文件存在且指纹正确；
- 历史Spot/MTF差值处于冻结容差；
- 均衡四指标全部通过；
- 模型及工作副本未变，连接已关闭；
- 审核记录为PASS；
- 九点批次、Slot5-6和工程结论继续锁定。
