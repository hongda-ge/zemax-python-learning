# Day 56：Slot 3 Day24 离线验收审批

## 为什么今天做

Day55 已经证明 Slot 2 的六案例批次完整、可复现且安全收尾，但“证据可信”不等于“可以直接执行下一任务”。Day56 用最小权限审批明确：下一步只能复用冻结证据做一次 Day24 离线验收。

## 和昨天的关系

- Day52 提供零偏移 `defocus_004` 的审核证据；
- Day55 提供六个非零离焦案例的审核证据；
- Day24 配置提供严格、均衡和宽松三套教学阈值；
- Day56 把这些输入绑定到 Day57 的一次性运行契约。

## 核心概念

### 1. 证据拼装

Day24 需要七个测量点。零偏移来自 Day51/52，六个非零点来自 Day54/55。审批必须明确两部分来源，避免漏掉控制组。

### 2. 阈值冻结

验收前先固定阈值，才能避免看到结果后再调整规则。四项指标分别判断，全部通过才算该案例通过。

### 3. 离线复用

Day57 不需要 Zemax。Spot 和 MTF 已在 Slot 2 计算完成，Slot 3 只负责依据规则分类和生成报告。

### 4. 最小权限

Day56 只允许 Day57 运行一次，不批准 Slot 4-6，也不允许把教学阈值解释成产品规格。

## 操作流程

先运行审批规划：

```powershell
python scripts/demos/day56_slot3_day24_acceptance_approval_plan.py
```

规划通过后，再生成审批记录：

```powershell
python scripts/demos/day56_generate_slot3_day24_acceptance_approval.py
```

## 完成标准

- Day52、Day55、Day42 和 Day24 指纹有效；
- 七个案例和三套教学阈值被冻结；
- 只释放 Day57 的一次离线执行；
- 不连接 ZOS-API，不计算新光学指标；
- Slot 4-6 继续锁定。
