# Day 28：验收阈值余量审计

## 为什么 Day27 之后还要看余量

Day27 得到两个采样包络通过候选：

```text
command_002：命令位置 +0.010 mm
command_003：命令位置 +0.020 mm
```

二者的负端、中心和正端三个离散状态都通过了四项均衡验收。但是 PASS 只表示跨过了阈值，并没有告诉我们距离阈值还有多远。

例如：

```text
MTF50 最小值 0.050001：PASS，但余量很小
MTF50 最小值 0.070000：PASS，余量较大
```

所以 Day28 不增加新光学计算，而是审计已有通过状态的阈值余量。

## 什么是有符号余量

为了让“正数代表通过、负数代表失败”，上限型指标和下限型指标采用不同公式。

### Spot 上限型指标

Spot 越小越好，因此：

```text
Spot余量 = 允许上限 - 实测值
```

例如 Spot 平均阈值为 `11.300 μm`，实测为 `11.100 μm`：

```text
余量 = 11.300 - 11.100 = +0.200 μm
```

### MTF 下限型指标

MTF 越大越好，因此：

```text
MTF余量 = 实测值 - 允许下限
```

例如 MTF30 最小值阈值为 `0.160`，实测为 `0.180`：

```text
余量 = 0.180 - 0.160 = +0.020
```

## 为什么取三个采样状态中的最小余量

每个候选有负端、中心、正端三个状态。某项指标的候选余量定义为：

```text
候选最小余量 = min(负端余量, 中心余量, 正端余量)
```

这相当于问：“在已测的三个定位状态中，这项指标最接近失败时还剩多少余量？”同时记录产生最小余量的状态，便于追踪风险来自哪一侧。

## 为什么不能把四项余量直接相加

四项指标包含不同单位：

- Spot 余量单位是 `μm`；
- MTF 余量没有量纲。

直接计算：

```text
0.2 μm + 0.02 MTF
```

在物理上没有明确意义。即使先归一化再相加，也必须提前声明权重及其工程依据。当前没有探测器、机构和任务优先级，因此 Day28 保持四项余量独立，不生成隐藏总分。

## 第一步运行方式

请在 VS Code 中运行：

```powershell
python scripts/demos/day28_acceptance_margin_audit_plan.py
```

计划脚本只会：

1. 校验 Day27 报告的 SHA256；
2. 确认只有 `command_002` 和 `command_003` 进入余量比较；
3. 确认六个采样状态全部通过；
4. 冻结四项余量公式；
5. 禁止跨单位求和、隐藏评分和唯一赢家。

它不会连接 ZOS-API，也不会创建新的光学结果或输出目录。

## 今天需要掌握的思想

1. PASS/FAIL 是门槛判断，余量是距离门槛的程度。
2. 包络余量应关注最不利采样状态，而不是只看平均值。
3. 不同单位的指标不能随意相加。
4. 每项指标可能由不同定位状态控制。
5. 多个指标可能支持不同候选，因此没有偏好时不应强选唯一赢家。

## 实际余量审计结果

### command_002：命令位置 +0.010 mm

| 指标 | 三点中的最小余量 | 控制实测位置 |
|---|---:|---:|
| Spot 平均 RMS | +0.266949 μm | 0.000 mm |
| Spot 最差视场 RMS | +0.419283 μm | 0.000 mm |
| MTF30 最小值 | +0.023562 | 0.000 mm |
| MTF50 最小值 | +0.011982 | 0.000 mm |

四项指标都由负误差端 `0.000 mm` 控制。换句话说，在这个三点包络中，实际位置向负侧偏移时最接近验收阈值。

### command_003：命令位置 +0.020 mm

| 指标 | 三点中的最小余量 | 控制实测位置 |
|---|---:|---:|
| Spot 平均 RMS | +0.188597 μm | +0.030 mm |
| Spot 最差视场 RMS | +0.567797 μm | +0.010 mm |
| MTF30 最小值 | +0.020236 | +0.030 mm |
| MTF50 最小值 | +0.010157 | +0.030 mm |

Spot 平均、MTF30 和 MTF50 由正误差端 `+0.030 mm` 控制，最差视场 Spot 则由负误差端 `+0.010 mm` 控制。这再次说明不同指标的最不利位置可以不同。

## 四项指标的独立余量领先者

| 指标 | 余量领先候选 | 最小余量 |
|---|---|---:|
| Spot 平均 RMS | command_002 | +0.266949 μm |
| Spot 最差视场 RMS | command_003 | +0.567797 μm |
| MTF30 最小值 | command_002 | +0.023562 |
| MTF50 最小值 | command_002 | +0.011982 |

`command_002` 在三项指标上具有更大的最小采样余量，`command_003` 在最差视场 Spot 上具有更大的余量。但“三项领先”不能自动变成总分胜利，因为：

- Spot 与 MTF 单位不同；
- 四项指标的重要性尚未由真实需求定义；
- 领先幅度不同，不能只按领先项目数量投票；
- 当前仍是三个离散状态的教学证据。

## 余量分布揭示的趋势

当候选命令从 `+0.010 mm` 移到 `+0.020 mm`：

- 最差视场 Spot 的最小余量增加；
- Spot 平均 RMS 的最小余量减少；
- MTF30 和 MTF50 的最小余量减少；
- 多项控制位置从负侧转移到正侧。

这与 Day23 观察到的离焦非对称性一致：移动像面会在不同视场和空间频率之间重新分配性能，而不是让所有指标同步变好。

## Day28 的正确结论

可以说：

> 在三个离散定位状态上，两个候选的四项最小余量均为正；`command_002` 的 Spot平均、MTF30和MTF50余量更大，`command_003` 的最差视场Spot余量更大。

不能说：

- `command_002` 已经是唯一最佳工程位置；
- 三项领先一定胜过一项领先；
- 四项余量可以直接相加；
- 三个采样点的余量代表连续区间余量；
- 教学阈值就是探测器或整机指标。
